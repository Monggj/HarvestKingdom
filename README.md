# Harvest Kingdom – Farming Simulation Game

A farming simulation game written in Java. Buy seeds, plant crops, water them, wait for them to grow, and sell the harvest to earn money. Game data is stored in a SQLite database, and the farm status is shown on an HTML page that opens in your browser.

> 🚧 **Status: In development.** The core farming loop works (buy, plant, water, grow, sell). More features are being added. See the [Roadmap](#roadmap).

## Features

- Buy seeds and plant them automatically in an empty field (a new field is created if all fields are in use)
- Crops grow day by day, with a growth percentage shown for each field
- Water level decreases every day and can be refilled by watering
- Sell harvested crops for money
- Start a new game at any time (money and day are reset, all fields are cleared)
- Farm status page (`farm.html`) with the player's day and money, field cards with growth and water bars, and a seed shop list with plant images

## Menu

| Key | Action |
|---|---|
| 1 | Buy seeds and plant them |
| 2 | Sell a crop (enter the field number) |
| 3 | Go to the next day |
| 4 | Water a field (enter the field number) |
| 5 | New game (reset) |
| 6 | Exit |

## Game Rules

- A new game starts with **$1,000** on **Day 1**.
- Each plant has its own grow days, seed cost, and sell price.
- Growth (%) = days since planting × 100 ÷ grow days. When the days passed reach the grow days, the field becomes `READY`.
- Each day, the water level of every growing field decreases by 20.

## Project Structure (MVC)

```
HarvestKingdom/
├── src/
│   ├── controller/   # Main, DayController, ShopController, FarmController
│   ├── entity/       # Player, Field, Plant, Animal, AnimalType, Transaction, WeatherLog
│   ├── model/        # Database access classes (JDBC + SQLite)
│   └── view/         # GameView (console menu), FarmView (HTML output)
├── img/                      # Plant images shown on farm.html
├── harvestKingdom.db         # SQLite database
├── sqlite-jdbc-3.36.0.3.jar  # SQLite JDBC driver
└── style.css                 # Styles for farm.html
```

- **Model:** reads and writes the SQLite database with JDBC
- **View:** console menu (`GameView`) and an HTML page generated by `FarmView`
- **Controller:** game logic such as buying, selling, and advancing the day

## Requirements

- Java 8 or later
- Eclipse IDE (or any Java IDE)
- [SQLite JDBC driver](https://github.com/xerial/sqlite-jdbc) (`org.sqlite.JDBC`), included in this repository as `sqlite-jdbc-3.36.0.3.jar`, added to the project's build path
- A desktop environment with a web browser (the farm page opens automatically)

## How to Run (Eclipse)

1. Clone or download this repository.
2. Import it into Eclipse as a Java project.
3. Add the SQLite JDBC `.jar` to the build path
   (Right-click project → Build Path → Add External Archives).
4. Make sure `harvestKingdom.db`, `style.css`, and the `img/` folder are in the **project root folder**.
5. Run `Main.java` (in the `controller` package) as a Java Application.
6. Use the console menu to play. `farm.html` is created in the project folder and opens in your browser.

> Note: The database and `farm.html` are accessed by relative path, so the program must be run from the project root.
